# NEXUS — Case Study

## Context

Colégio Neuza Dutra uses technology as part of its educational environment, including robotics, Maker activities and digital learning experiences.

NEXUS was conceived as a dedicated digital environment capable of organizing these experiences in a way that was more closely aligned with the school's own projects and workflows.

## The challenge

The platform needed to serve different audiences while remaining simple enough for school use.

Key challenges included:

- Different permissions for students, teachers and administrators
- Organizing a growing amount of educational content
- Maintaining student-specific activity data
- Creating a consistent user experience
- Integrating external interactive tools
- Improving the product continuously after real-world use

## The solution

NEXUS was designed as a centralized educational platform with authenticated access and structured content.

Instead of treating lessons as isolated pages, the platform organizes them in a hierarchy that can grow with the school:

**School year → Stage → Chapter → Lesson**

This enables the same product to support multiple educational programs and grade levels.

## Real-world iteration

One of the most valuable aspects of the project is that it was not developed only as an academic exercise.

The platform was designed for a real educational context, which required adjustments based on actual use, user behavior and new requirements.

This changed my understanding of software development: building the first version is only part of the work. A useful product also requires maintenance, testing, feedback and continuous refinement.

## NEXUS Blocks

NEXUS Blocks expanded the project beyond a content platform.

It provides a block-based programming environment for robotics activities and is integrated into NEXUS so that students can move between learning content and practical programming experiences.

This integration introduced additional challenges related to user context, persistence and embedded applications.

## Outcome

NEXUS became a practical example of how information systems can connect:

- Users
- Educational content
- Authentication
- Data
- Interactive tools
- Real organizational needs

For me, the project represents the intersection of **Information Systems, Web Development, Product Design and Educational Technology**.
