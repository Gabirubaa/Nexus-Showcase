# Privacy and Security

NEXUS operates in a real educational environment. For this reason, this public repository is intentionally limited to portfolio and project-documentation material.

## Not published

The repository must not contain:

- Student names, emails or identifiers
- Teacher or employee personal data
- Production credentials
- API keys or secrets
- Environment variables
- Private Firebase configuration beyond what is safe for public client applications
- Database exports
- Production security rules
- Internal administrative screenshots
- School documents containing personal information
- Passwords or access tokens

## Screenshots

Only screenshots that contain **no personal or confidential information** should be added.

When in doubt, crop, blur or omit the image.

## Source code

The production source code is maintained separately and is not part of this public showcase repository.

## Purpose

This repository exists exclusively to demonstrate:

- Product conception
- Technical reasoning
- Project architecture at a safe level of abstraction
- Professional experience gained through the project
