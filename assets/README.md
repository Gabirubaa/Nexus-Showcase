# Screenshots

Add only public or sanitized screenshots of NEXUS here.

Recommended images:

1. `home.png` — public landing page
2. `login.png` — login interface without credentials
3. `student-dashboard.png` — sanitized student experience
4. `lesson.png` — example lesson without student information
5. `nexus-blocks.png` — integrated programming environment

## Important

Do not upload screenshots containing:

- Student names
- Emails
- User IDs
- Grades
- Private class information
- Administrative data
- Access credentials

Recommended width: **1400–1800 px**.

Once images are added, they can be referenced from the main README using:

```markdown
![NEXUS home](assets/home.png)
```
